# Design context

Vite, React and Tailwind CSS. User requested a straightforward one-page showcase, their supplied Codeshor logo and larger readable typography.

- Use the original raster logo on its navy background (#091433).
- White main content, dark text and blue actions. No gradients, ornamental type, floating decorations or animation.
- Body copy: 16px. Intro copy: 18px. Main heading: 36px mobile, 48px desktop.
- Three actual website screenshots, external live demo links and design-aware contact flow.
- Keep components, data, configuration and assets under src/.
- Preserve clearly marked dummy contact mode until a real WhatsApp number is supplied.
- All edits stay in this showcase project.
